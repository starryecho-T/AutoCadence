注意事项：
- 沙箱/受限环境内以后台服务方式运行会无法在 `runs/` 建目录（WinError 5）——演示用真实终端前台启动 `serve.py`，或用 `tools/*` 前台驱动。
- 单 worker 串行：演示时不要并发提交多个任务；队列上限 20。
- 若换机器：`config.local.json` 的 SSH/路径与 `VAI_CORS_ORIGINS` 需按 README 配置；不共享私钥。
