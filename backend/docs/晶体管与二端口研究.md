# 晶体管、扫描与二端口研究

在通用电路 v2 中新增 BJT（NPN/PNP）、四端 PMOS、VCCS/VCVS/CCCS/CCVS，以及参数族、Y 参数提取、等效电路独立仿真和曲线比较。所有数值来自真实 Spectre 运行。现有 RC v1 接口保持兼容。

## 从界面开始

在“通用电路 → 连接描述 → 电路示例”中选择：

| 示例 | 用途 |
|---|---|
| NPN 共射转移曲线与工作区 | RB=1 kΩ、RC=10 kΩ、VCC=5 V，扫描 Vin，输出工作区与分段理论误差 |
| PMOS 输出特性与栅压扫描 | 源极为参考的输出特性族 |
| PMOS 接 VDD 的输出特性 | 源极接 5 V，按相同 VSG、VSD 与前者比较 |
| 共基极小信号模型 | RBE、RCE、gm 受控源的 Y 参数与独立等效验证 |
| 有偏置 BJT | 保持偏置的小信号 Y 参数与等效验证 |
| 四种线性受控源 | 校验四种增益、控制源和电流方向 |
| 参数扫描与跨组曲线比较 | 修改 R 后保留每组曲线、计算误差和容差判定 |

预检、确认后运行。结果页可选择扫描组或叠加曲线，AC 可切换幅值、相位、实部和虚部。矩阵、工作区和误差表在“分析与比较”中显示。

## 元件与模型

```text
Q1 collector base emitter generic_npn
Q2 collector base emitter generic_pnp
M1 drain gate source bulk generic_pmos w=10u l=1u m=1
G1 out 0 control 0 0.001
E1 out 0 control 0 2
F1 out 0 VPROBE 3
H1 out 0 VPROBE 2k
```

Q 的引脚顺序是 C/B/E，可选衬底由 analogLib 接地；M 是 D/G/S/B，必须明确衬底连接。G、E 的末值分别为跨导 S 和无量纲电压增益。F、H 的末值分别为无量纲电流增益和转阻 Ω，控制量为指定独立电压源正端流入的电流；串联零伏源可作为电流探针。输出电流方向从输出正端指向负端。控制源引用会被检查，不能引用电阻或不存在的源。

默认 BJT 使用 Spectre `bjt` 教学模型，默认 PMOS 使用 `mos1 type=p` 一级模型。它们不是工艺库器件。模型参数通过 JSON 的 `models` 显式指定，并由组件的 `model` 引用：

```json
[
  {"id":"my_npn","type":"bjt","polarity":"npn","saturation_current_a":1e-15,"forward_beta":100,"forward_early_voltage_v":100},
  {"id":"my_pmos","type":"mos1","threshold_voltage_v":-0.7,"transconductance_a_v2":0.0001,"channel_length_modulation_per_v":0.02}
]
```

BJT 还可配置反向 β、发射系数、内部电阻、BE/BC 结电容和正向渡越时间；PMOS 可配置体效应、表面势和重叠电容。字段和范围见 [v2 schema](../contracts/v2/task.schema.json)。不接受用户执行代码、任意模型文件或外部 PDK 路径。

电流观测支持 `.save I(Q1,c) I(Q1,b) I(Q1,e) I(M1,d) I(M1,g) I(M1,s) I(M1,bulk)`，正方向为流入指定端子。其他两端器件可用 `I(R1,n)` 反向观测。器件参数写 `P(Q1,region)`、`P(Q1,gm)` 等：BJT 支持 region/gm/vbe/vbc/vce/ib/ic，PMOS 支持 region/gm/gds/vgs/vds/vth/ids。器件参数仅在不含 AC 的 OP/DC/TRAN 任务中保存；AC 任务保存电压与端电流。

## 参数族与曲线比较

```text
.dc VD 0 -5 -0.05
.step VG dc -1 -1.5 -2 -2.5
```

独立 DC 扫描是内层，`.step` 是外层参数族。保留原参数 `base`，组合按输入顺序编号 `s000`、`s001` 等。两轴采用笛卡尔积，最多 20 组，不能扫描同一字段或覆盖内层 DC 的同一源。每个变体都会重新验证参数范围和理想电压约束；不会修改原任务。

可扫描字段：独立源 dc、电阻 resistance_ohm、电容 capacitance_f、电感 inductance_h、受控源 gain、PMOS width_m/length_m、BJT area。波形源的 dc 参数不用于外层扫描。

```text
.compare check dc s1 s1 base s000 0.001 1n
```

依次为编号、分析、实际信号、参考信号、实际组、参考组、相对容差、绝对容差。JSON 的 `comparisons` 还支持 `scale`。比较单位必须相同，默认 scale=1；目标为 `actual = scale × reference`。实数/复数波形在双方坐标点并集上线性插值，要求同范围、不外推；复数直接比较，保留相位误差。输出最大绝对误差、RMSE、最坏坐标和最大容差比，判据为 `|error| ≤ atol + rtol × |reference|`。失败会让 `requirements_status=FAIL`，即使数值执行本身成功。

## Y 参数与等效验证

```text
VE emitter 0 DC 0 AC 1
VC collector 0 DC 0
RBE emitter 0 1k
RCE emitter collector 100k
GM emitter collector emitter 0 0.04
.ac 10 100k 10
.save I(VE) I(VC)
.twoport VE VC 1k
```

两个端口以已存在的独立电压源定义，源正负端确定端口电压。原 DC 值保持不变；其他独立 AC 激励归零。分别运行 `(V1,V2)=(1,0)`、`(0,1)`，得到整段复数 Y(f)。电流采用流入网络为正，即 `Iport=-I(test source,p)`。默认不与参数族组合。

第三次以 `(1∠0°, 0.37∠37°)` 同时激励两个端口，检查 `I=YV`。参考频率内插得到矩阵，并生成含两个激励源、四个 VCCS 的独立等效任务。此任务重新经过 Cadence 建图、读回、网表验证、Spectre、截图与数值检查，再比较两个端口在整个请求频带内的复数电流。不是只比较一张图或只检查参考频点。

上例理论矩阵为：

```text
Y11 = 1/RBE + 1/RCE + gm = 0.04101 S
Y12 = -1/RCE               = -0.00001 S
Y21 = -1/RCE - gm          = -0.04001 S
Y22 = 1/RCE                = 0.00001 S
```

`.twoport ... extract_only` 仅提取，不自动生成等效。完整 JSON 的 `two_port` 可设置 `relative_tolerance`、`absolute_tolerance_a`、`max_imaginary_admittance_s`。

提取可包含动态网络的复数 Y；自动构造只支持参考频率处虚部足够小的实数 Y。明显虚部会被明确标记为不能用四个实数 VCCS 表达，并停止自动等效构造；频率变化导致的差异会在整频带比较中失败。对有偏置 BJT 的结果仅说明该偏置附近的交流小信号等效，不声称直流、大信号或其他偏置等效。

## BJT 转移与理论比较

```text
.dc VIN 0 1.2 0.005
.transfer Q1 VIN VCC RB RC
```

该自动理论流程只接受接地发射极、输入电压源、VCC、RB、RC 和 NPN 的五元件无负载共射拓扑；不适用时直接拒绝。任务需独立于 AC。内部增加集电极电压和 region 观察量，因此用户观测量最多 14 个。

Spectre BJT region：0 截止、1 正向放大、2 反向放大、3 饱和、4 击穿。程序报告实际采样的工作区范围，不把固定 0.7 V 当成真实模型的硬切换点。分段理论使用：

```text
Ic = clamp(beta*(Vin-VBEon)/RB, 0, (VCC-VCEsat)/RC)
Vout = VCC-Ic*RC
```

VBEon 默认 0.7 V，VCEsat 默认 0.2 V，β 取所选 BJT 模型。它是教学近似，与连续 BJT 模型的误差会如实报告，不按精确相等判失败。RB 限制基极电流；移除 RB 后不能继续套用该公式。
