## 5. 重复执行

常规检查：

```powershell
cd D:\GitHub\circuit-sim\backend
.\setup_backend.ps1
.\.venv-local\Scripts\python -m pytest tests -q
.\.venv-local\Scripts\python tools\verify_release.py --run-id vai_20261018_081516_bc09f692e652
cd ..\frontend
npm test
npm run build
```

真实回归会使用服务器许可证。先关闭指向同一 `runs/` 的其他后端实例，按顺序执行：

```powershell
cd D:\GitHub\circuit-sim\backend
$env:VAI_SUMMARY_PATH = "$PWD\docs\m5_m2_latest.json"
.\.venv-local\Scripts\python tools\m2_regression.py
.\.venv-local\Scripts\python tools\failure_regression.py --output docs\m5_failure_latest.json
Remove-Item Env:VAI_SUMMARY_PATH
.\start_backend.ps1
```

在另一个终端启动前端。具备 Playwright 的测试环境中，设置 `PLAYWRIGHT_MODULE`（可选，模块已安装时无需设置）、`PLAYWRIGHT_CHANNEL=msedge`、`VAI_LIVE_URL=http://localhost:5173`、`VAI_BROWSER_OUTPUT` 后运行 `npm run test:live`。该命令会通过浏览器点击确认并提交一次真实仿真；需要前面的真实失败回归记录用于失败页验收。

离线界面回归使用 `npm run test:browser`，与真实验收分开。它使用临时目录和失败夹具，只复制已有真实历史记录验证显示，不访问远程 Cadence。

- 通过的是本版本的一阶 RC 低通浏览器流程；通用电路拓扑和任意自然语言 agent 未在本轮实现。
