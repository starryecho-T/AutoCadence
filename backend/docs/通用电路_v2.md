# 通用电路自动仿真 v2

本实现把固定 RC 模板扩展成明确拓扑驱动的仿真流程。支持电阻、电容、电感、二极管、独立电压源、独立电流源、理想线性运放与导线。用户可组合这些元件，并指定工作点、直流扫描、交流小信号或瞬态分析。执行仍使用实际 Cadence IC617 / Spectre MMSIM151，数值、原理图与波形截图来自同一次运行。

## 使用

按项目 README 启动后端和前端，在输入页选择“通用电路”。选择一个示例，修改元件、节点、数值与分析设置，点击“解析并检查电路”。确认页显示导线合并后的连接、模型提示和执行网表；只有点击“确认并开始仿真”才会提交。完整 JSON 可编辑，编辑后必须重新检查。

结果页显示实际节点／支路数据、独立的目标指标判定、Cadence 原始截图、报告和原始导出文件。AC 数据保留复数，界面可切换实部、虚部、幅值和相位。绘图约保留 1000 点，测量计算使用完整数据。

截图输入通过用户在“图片识别设置”配置的视觉服务输出连接列表，并列出识别不确定项。用户必须核对原图与连接描述；系统不会根据缺失的连线或数值自动补出电路。本次验收覆盖结构化输入、服务端预检和浏览器流程；未调用用户的外部视觉模型进行准确率验收。

## 连接描述

这是本项目的连接列表语法，不是完整 SPICE 语言。地节点必须写 `0`。同名节点表示电气相连，导线将两个节点合并；图中交叉是否连接必须由输入明确。编号和节点名使用英文字母开头的字母、数字或下划线，最长 32 个字符；大小写不同的重名不允许。

```text
V1 vin 0 SINE 0 1 1000 AC 1
R1 vin feedback 10k
R2 feedback out 20k
U1 0 feedback out
.op
.ac 10 100k 30
.tran 4m 1u
.save V(vin) V(out) V(feedback) I(R1)
```

此例为理想反相放大器，闭环增益为 -2。各元件写法如下：

| 类型 | 写法 | 方向／参数 |
|---|---|---|
| 电阻 | `R1 a b 1k` | 电阻值，单位 Ω，必须大于零 |
| 电容 | `C1 a b 1u [ic=1]` | 单位 F，初始电压方向 V(a)-V(b) |
| 电感 | `L1 a b 10m [ic=0.01]` | 单位 H，初始电流方向 a→b |
| 二极管 | `D1 a k [model_id]` | 阳极、阴极；缺省采用 generic_diode |
| 理想运放 | `U1 plus minus out` | 同相输入、反相输入、输出；也接受 O 开头 |
| 导线 | `W1 a b` | 合并节点，不生成独立仿真器件 |
| 电压源 | `V1 p n DC 5` | V(p)-V(n) 为正 |
| 电流源 | `I1 p n DC 0.01` | 电流正方向 p→n |

方括号表示可选项，不写进实际描述。数值使用 SI 或 `k`、`meg`、`M`、`m`、`u`、`n`、`p` 前缀；`M` 为兆，`m` 为毫。支持科学计数法。空白行、`*` 开头行和分号后的注释会忽略。

电源支持 `DC 值`、`SINE 偏置 幅度 频率`、`PULSE 低 高 延迟 上升 下降 脉宽 周期`，其末尾可附加 `AC 幅度 [相位度]`。PWL、电源正弦相位／延迟和自定义二极管模型通过 JSON 设置。

| 分析 | 写法 | 含义 |
|---|---|---|
| 工作点 | `.op` | 输出一组 DC 标量 |
| 直流扫描 | `.dc V1 -1 1 0.01` | 对指定独立源的 dc 值扫描；也支持负步长 |
| 小信号交流 | `.ac 10 100k 50` | 起止频率 Hz、每十倍频点数；至少一个源需有非零 AC 幅度 |
| 瞬态 | `.tran 10m 1u [ic]` | 终点、最大步长，单位 s；ic 启用元件初始值 |
| 观测 | `.save V(a) V(a,b) I(R1)` | 对地电压、差分电压、两端元件正向支路电流 |

每种分析最多一个，可同时请求四种。直流范围必须包含整数个步长。交流结果是直流工作点附近的线性化响应；二极管整流应使用瞬态分析。DC 扫描源的 `dc` 参数，瞬态源波形独立生效。

## JSON、模型与指标

完整 JSON 示例在 [examples/general](../examples/general)，字段定义在 [task.schema.json](../contracts/v2/task.schema.json)。预览接口会补齐缺省字段。所有量使用 SI，未知字段与非有限数值会被拒绝。常用字段为 `components`、`models`、`analyses`、`signals`、`measurements` 和 `temperature_c`。

`signals` 以自定义 id 定义电压或支路电流；连接列表中的 `.save` 从 s1 开始编号。测量用信号 id 和分析名引用数据。例如给反相放大器 JSON 添加：

```json
"measurements": [{
  "id": "closed_loop_gain",
  "analysis": "ac",
  "signal": "s2",
  "operation": "at",
  "representation": "magnitude",
  "at": 1000,
  "minimum": 1.999,
  "maximum": 2.001
}]
```

此指标的量是该信号在 1 kHz 的电压幅值；因本例输入 AC=1 V，数值也等于闭环增益。系统不会自动把输出幅值解释为任意输入下的传递函数。

测量支持 final、min、max、mean、rms、peak_to_peak、at，以及 AC 的 real、imag、magnitude、phase_deg。瞬态 mean 和 rms 按实际时间间隔积分，at 对完整采样插值，AC 先插值复数再取幅相。相位是主值，范围约 -180°～180°。AC／DC 的 mean、rms 为采样点统计，不是带宽积分。

二极管模型支持饱和电流、发射系数、串联电阻、结电容、渡越时间与可选击穿电压；缺省为简化通用模型，不代表某个厂商料号。理想运放用 Verilog-A 的约束实现输入零电流、V+＝V- 和自由输出电压；没有电源轨、饱和、带宽或压摆率。外围电路必须给出一致、可解的反馈约束。

电容／电感的初始参数只有在瞬态 `use_initial_conditions=true`（连接列表 `.tran ... ic`）时启用；默认从直流稳态启动。启用时使用 Spectre 的元件初始条件求解 `ic=dev`，保留一致初始化，支持两端均不接地的电容。初始化施加约束时的数值电阻 `initial_condition_resistance_ohm` 默认 0.001 Ω，可在 JSON 调整；它仅用于初始化，不是实际电路电阻。低阻抗约束可能使 t=0 实际值偏离指定值，应保存相关信号并验收。这里不接受 SPICE 的 `uic` 跳过初始化语义：Spectre 在 skipdc 模式会忽略元件上的 ic 参数。该行为已使用服务器自带 `spectre -h tran` 和实际初始条件回归核实。

## 自动执行

```mermaid
flowchart LR
  A[连接描述或截图识别] --> B[严格电路数据与引用校验]
  B --> C[导线归并与拓扑预检]
  C --> D[用户核对并确认]
  D --> E[隔离工作目录与 Cadence 建图]
  E --> F[读回引脚并生成网表]
  F --> G[核对器件和参数]
  G --> H[Spectre 仿真与数值导出]
  H --> I[真实截图与数据完整性校验]
  I --> J[测量和独立目标判定及报告]
```

规范化中间数据生成安全的内部节点／实例名，组件注册表决定符号、端子、CDF 属性和 Spectre 模型。导线经并查集合并。预检拒绝缺地、全端短接、完全隔离网络、矛盾的固定理想电压源等；预检通过仍可能出现直流悬浮、矩阵奇异或非线性不收敛，这些由仿真器返回明确失败和日志。

SKILL 建图并保存后，独立重新打开数据库核对每个引脚；Cadence 生成的器件连接与数值必须匹配已确认电路。实际执行网表由验证后的中间数据生成，并显式加入所请求的模型、分析和保存设置。原始 Cadence 网表、执行网表及各自哈希记录在 `netlist_original.scs`、`input.scs` 和 `provenance.json`，不会把二者称为字节完全一致。

每次运行保留 task.json、compiled.json、signals.json、原始导出 txt、waveforms.json、metrics.json、Spectre 日志、真实截图、保护文件哈希核对和 HTML／Markdown 报告。截图校验检查实际绘图区，允许单条曲线、常数曲线和不同颜色；数值正确性另行验证。通用任务使用独立分析器，不套用 RC 截止频率或固定曲线形状的规则。

`execution_status` 表示执行完成，`validation_status` 表示导出数据有限、范围完整且采样对齐，`requirements_status` 单独表示用户给定上下界是否达标。不设置指标上下界时为 NOT_SPECIFIED；流程成功不会自动判定满足题意。

## 接口和限额

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v2/capabilities` | 元件、分析、限额与示例 |
| POST | `/api/v2/parse` | `{ "text": "连接描述或 JSON" }` → 预览，不提交 |
| POST | `/api/v2/preview` | CircuitTask JSON → 重新预检 |
| POST | `/api/v2/runs` | 提交已核对的 CircuitTask |
| GET | `/api/v2/runs`、`/api/v2/runs/{id}` | 历史与状态；也支持现有 v1 读取路由 |

任务采用 schema_version=2.0；结果外层沿用 schema_version=1.0 的任务／阶段／工件封装，其中 task 为 v2 数据。工件继续使用现有 `/api/v1/runs/{id}/artifacts/{id}` 地址。新增契约在 contracts/v2，原 contracts 根目录冻结文件保持原哈希。实时 `/docs` 包含新增接口。

限额：100 个元件、16 个观测信号、30 个模型、100 个测量；每种分析一次；AC 预算 10000 个间隔，DC 最多 10000 个步长，瞬态 stop/max_step≤200000。仿真器自适应步进仍可能产生更多点，实际导出超过 400000 点会拒绝；远程超时和证据包体积也受原流水线限制。波形 PWL 最多 50 个点。暂不支持导线／理想运放的电流观测、晶体管、耦合电感、受控源、外部子电路、自定义可执行网表和自动器件选型。

## 验收与重跑

11 个真实案例已通过：电阻分压与导线、OP 加反向 DC 扫描、RC 高通、RLC、二极管半波整流、理想反相放大器、二极管 I-V、电流源 RL、电感初始电流、浮置电容初始电压、PWL 加电容初始电压。每个案例都经过实际建图、连接读回、网表核对、Spectre、导出、截图、数值目标判定和报告。运行编号、实测指标和关键文件哈希见 [general_regression_summary.json](general_regression_summary.json)；完整证据位于本机 backend/runs 对应目录，未提交到源码仓库。

```powershell
cd D:\GitHub\circuit-sim\backend
.\.venv-local\Scripts\python.exe -m pytest tests -q
.\.venv-local\Scripts\python.exe tools\verify_release.py
# 使用服务器许可证；全部真实回归，或附加 --case inverting 选择单个案例
.\.venv-local\Scripts\python.exe tools\general_regression.py
# 直接仿真一个 JSON
.\.venv-local\Scripts\python.exe run_task.py examples\general\inverting.json

cd ..\frontend
npm test
npm run build
# Playwright 需已安装可用浏览器；本机验收使用 Edge
$env:PLAYWRIGHT_CHANNEL = 'msedge'
node tests\general_browser.mjs
```

后端单元／接口测试、前端测试、类型检查和生产构建均已通过；通用及原 RC 浏览器检查通过；原冻结证据审计通过。浏览器测试提交的是明确标记的失败夹具，成功结果展示取自相同 run_id 的历史真实证据，不把夹具当成新仿真。

通用电路表示可组合支持清单中的器件，不保证所有理想拓扑都有解或能收敛。新输入需要明确参数和连接；当前不支持仅凭“帮我设计任意电路”自动补齐题意。已有 Release 的 EXE 尚未重新打包，使用当前源码启动或重新构建桌面版后才包含本功能。
