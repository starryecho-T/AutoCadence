## 5. 失败判定链路（环境缺失注入）

- **配置**：[examples/config_env_missing.json](../examples/config_env_missing.json)（`virtuoso_bin` 指向不存在的路径）
- **执行**：`VAI_CONFIG=examples/config_env_missing.json python run_task.py examples/rc_m2_a.json --run-id vai_m2_envfail_probe`
- **结果**：upload 成功 → 远程 preflight 立即失败 → 证据照常回传（download 成功）→ `RUN_FAILED`，CLI 退出码 1
- **持久化证据**（runs/vai_m2_envfail_probe/）：
  - `cli_result.json`：`{"status":"failed","code":"ENVIRONMENT_MISSING","stage":"preflight","message":"virtuoso_bin not found"}`
  - `evidence/worker_result.json`：同错误码，`protected_unchanged: true`
- 判定链覆盖：远程阶段失败 → 状态事件回传 → 本地 PipelineError 带原始错误码 → 终态 failed + 退出码非零 + 证据留存。
