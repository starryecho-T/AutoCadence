# 使用自己的仿真服务器

AutoCadence 0.7.0 面向“每人在自己的电脑上使用”：桌面程序自带本机后端，每个 Windows 用户填写自己的 SSH 连接信息。没有共享的内置账号密码。

## 连接

在左侧“仿真服务器”填写服务器地址、端口（默认 22）、账号，并选择账号密码或私钥文件。首次连接时向管理员核对显示的 SHA256 主机指纹；确认前不会发送登录密码。已保存的主机身份发生变化时连接会被拒绝，应先向管理员核实。

点击“连接并保存”只检查登录和环境路径，不启动仿真、不占用 Cadence 许可。程序默认加载 `/etc/profile`，探测 `virtuoso`、`spectre` 和 Cadence 的 `cds.lib`。高级设置可手动填写环境脚本和程序路径，路径使用无空格的 Linux 绝对路径。默认任务目录为服务器当前用户主目录下的 `.autocadence/runs`，每次任务有独立子目录。

私钥文件保存在用户自己的电脑上，不上传到服务器；加密私钥可填写口令。旧服务器需要时启用“旧服务器 RSA 兼容模式”。每次仿真使用保存的连接设置，正在仿真或队列非空时不能切换服务器。

## 服务器要求

连接成功表示 SSH 与指定程序路径可用，不等于服务器已具备全部仿真依赖。服务器须事先配置：

- 可用且已授权的 Cadence Virtuoso / Spectre，以及 `analogLib` 等配套库。
- Bash、tar 和 Python 2.6/2.7（当前远端 worker 使用 `python` 命令及 Python 2 语法）。
- 原理图和波形截图所需的图形工具，具体依赖见后端 README。
- 当前账号对专用运行目录的读写权限，以及正确的许可环境变量。

程序支持各用户提供自己的连接信息；不包含 Cadence 安装包或许可。管理员提供的环境初始化脚本通常用于加载程序路径、动态库和许可设置。

## 密码与本机配置

默认密码只保存在本次后端进程内存中，重启后需要重新输入。勾选“记住密码”后，Windows 使用当前用户的 DPAPI 加密保存到 `%LOCALAPPDATA%/AutoCadence/connection.json`。更换 Windows 用户或电脑后需重新填写，设置中可随时清除。

SSH 密码不进入 localStorage、AI 对话、仿真输入压缩包或报告；配置查询接口不返回密码。服务器设置接口仅接受本机访问。该模式用于个人桌面程序，不提供多人共享 Web 服务器的账号隔离。

本机已有的 `backend/config.local.json` 可继续使用，首次在界面保存后改用当前用户的连接配置。旧文件不随 EXE 发布。独立后端可通过 `VAI_CONNECTION_FILE` 指定配置位置。
